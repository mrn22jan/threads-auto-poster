# Claude in Chrome 用｜Threadsリプ全件収集プロンプト

使い方：Chromeで対象投稿を開いた状態で、下の「プロンプト本文」をそのまま Claude in Chrome に貼る。
出てきたCSVを、このチャット（Claude Code）に貼れば、既存台帳（`看護師実声_採取台帳_追記_260927_意識低い系.csv`）と重複チェックして追記する。

---

## プロンプト本文

```
今開いているThreadsの投稿（https://www.threads.com/@moose.6927422/post/Ddx3eDIFKFN）について、リプライを「すべて」「一語一句そのまま」書き出してください。要約・言い換え・省略は一切しないでください。

【手順】
1. 投稿本文をまず書き出す（改行・絵文字もそのまま）。あわせて、いいね数・返信数・リポスト数・シェア数を記録する。
2. リプライの並び順を「最近」に切り替える。
3. ページの一番下までスクロールし、新しいリプが読み込まれなくなるまで繰り返す。
4. 「返信を表示」「さらに表示」「もっと見る」など、折りたたまれている部分はすべて開く。スレッド内の返信（投稿者 moose.6927422 の返信、リプ主の再返信を含む）も1件ずつ書き出す。
5. 途中で「…もっと見る」で本文が切れているリプは、開いて全文を取る。
6. 最後に、書き出した件数と、投稿に表示されている返信数を比べる。差がある場合は、差の件数と「見つけられなかった理由の推測」（非表示・削除・読み込み不可など）を書く。

【書き起こしのルール】
- 本文は画面に表示されている文字を一字一句そのまま写す。誤字・脱字・句読点・全角半角・絵文字・「笑」「w」・空行もそのまま。
- 読めない部分があっても推測で埋めない。その箇所は〔判読不可〕と書く。
- ユーザー名は @なしで、表示どおりに書く（例：spoon.0507）。
- 画像やスタンプだけのリプは、原文欄に〔画像のみ〕〔スタンプのみ〕と書く。
- 同じ人が複数回リプしていても、すべて別行で書く。

【出力形式】
CSV（UTF-8）で出力する。1行目は次の見出しにする。
番号,返信者,投稿者か,返信先,相対時刻,いいね数,返信数,原文,備考

- 番号：上から1,2,3…
- 投稿者か：moose.6927422 本人なら「はい」、それ以外は「いいえ」
- 返信先：元投稿への直接リプなら「元投稿」、誰かへの返信ならその人のユーザー名
- 相対時刻：画面の表示どおり（例：3時間、2日）
- いいね数・返信数：表示が無ければ 0
- 原文：必ずダブルクォートで囲む。本文中の " は "" にする。改行は改行のまま入れる
- 備考：〔判読不可〕の理由や、本文が途中で切れていた等の気づき

出力が長くて1回で出し切れない場合は、「つづく（次は番号○○から）」と書いて止め、私が「続けて」と送ったら続きから出す。途中で番号を飛ばしたり、重複させたりしない。

最後に、次のサマリーを付ける。
- 取得日時
- 元投稿のいいね数・返信数・リポスト数・シェア数
- 書き出した件数（うち投稿者の返信件数）
- 表示上の返信数との差と、その理由
```

---

## 受け取ったあとの処理（Claude Code側）
1. 貼られたCSVを `knowledge/` に保存する（原本）
2. 既存台帳と「返信者＋原文」で突き合わせ、新規分だけを台帳形式（採取日,出典URL,媒体,原文,痛みの分類,年次・属性,使用済みアカウント,使用日,備考）に変換して追記する
3. 既存行で〔判読不可〕だった箇所が埋まる場合は、その行を補完する
4. commit・push し、新規件数と、たらこ朝シリーズで使える実声の残数を報告する
